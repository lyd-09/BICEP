\section*{\centering{\textbf{Purpose}}}
This code implements fresnel and fraunhofer diffraction techniques, as well as beam steering to accurately incorporate all aspects of the BICEP Array calibration process. Replicating this process can allow us to compare the data from the telescope beam maps to the simulation and ultimatly finding a quantitative assessment of how the mirror non-flatness might be affecting areas of the beam maps.

\section*{\centering{\textbf{Aperture Creation}}}
The aperture function focuses on creating a 2d spatial grid that defines a circular aperture.
 It uses an N number of grid points along each axis, and grid spacing (dx) in the x and y directions.
 The aperture is gnerated with a Gaussian edge taper to simulate real teqniques. This means that some of the parts of the grid
 are non-zero, simulating a circular aperture. The function used to help create this is as follows:
 \begin{equation*}
    r = \sqrt{x[i,j]^2 + y[i,j]^2}
\end{equation*}


The dx remains the same for the aperture function and the fresnel function, since both use the same physical grid spacing. (1)

The coordinate array is centered at zero and a gaussian taper is applied to replicate the illumination of the aperture in experimental values.

\section*{\centering{\textbf{Fresnel Diffraction}}}
This function uses fresnel teqniques as found in (ref Optical physics third edition) to calculated the diffraction pattern from the aperture onto the mirror. 
Rather than using an FFT here, a for loop is utilized with the diffraction by Huygen's principle:
\begin{equation*}
    E(x',y') = \iint A(x,y) \frac{e^{ikd}}{d} dx dy 
\end{equation*}
The for loop ensures that the Fresnel diffraction teqnique is preserved and accurate in the near field. 

This function also accounts for the complex phase shift that is created from the tilted mirror 

% also known as rayleigh - sommerfeld/fresnel integral


ACCOMODATING THE ANGLED REFLECTION:
(multiply by -1 terminology)
Since the Fraunhofer calculation is simulated as it reflects off the mirror at a 45 degree angle, the Near field output needs to be multiplied by -1 to account for this change in direction. 
According to Euler's formula, we can multiply the following phase shift by the produced output to achieve this effect.
 \begin{equation*}
    e^{i \pi} = cos(\pi) + i sin(\pi) = -1 + 0j = -1
\end{equation*}

The nearfield output from the fresnel diffraction function is input into the fraunhoffer function. 
This allows for all features applied to be carried through accurately into the far field projection. 

Fresnel diffraction ingegral caluclation using a single FFT method explicity includes the distance and quadratic phase factor to output a grid in physical mm of distance. 
To go from this output to an angular deviation, the following equation can be used:
 \begin{equation*}
    \tan(\theta_x) = \frac{x_2}{z_1}
\end{equation*}
Where z1 is the Far Field propogation distance. This formula yields an angle in radians which can then be converted to degrees for plot interpretation.
