\section*{\centering{\textbf{Purpose}}}
This code implements fresnel and fraunhofer diffraction techniques as well as beam steering to accurately incorporate all aspects of the BICEP Array calibration process. Replicating this process can allow us to compare the data from the telescope beam maps to the simulations maps. Ultimatly finding a quantitative assessment of how the mirror non-flatness might be affecting areas of the beam maps.

\section*{\centering{\textbf{Aperture Creation}}}
The aperture function focuses on creating a 2d spatial grid that defines a circular aperture.
 It uses an N number of grid points along each axis, and grid spacing (dx) in the x and y directions.
 The aperture is gnerated with a Gaussian edge taper to simulate real teqniques. This means that some of the parts of the grid
 are non-zero, simulating a circular aperture. The function used to help create this is as follows:
 \begin{equation*}
    r = \sqrt{x[i,j]^2 + y[i,j]^2}
\end{equation*}


The dx remains the same for the aperture function and the fresnel function, since both use the same physical grid spacing. (1)

The coordinate array is centered at zero and a gaussian taper is applied to replicate the illumination of the aperture in experimental values.

Beam steering teqniques are also applied during this step using a tilt phase calculation for the whole grid. This calculation can be seen below.
\begin{equation*}
    \phi = k(xcos(theta) + ysin(theta))tan(\alpha)
\end{equation*}

In order to steer the beam source two different angles must be defined. Here, there is a tilt angle ($$\alpha$$) and a rotation angle ($$\theta$$) on the x-axis. (insert ref)

alpha steer is the tilt angle. This describes the angle the beam makes in the z direction.

theta steer is the azamuth angle, which is the xy direction that the beam is leaning in. 

spactial frequencies and slope can then be defined using trigonometry. 

When both angles are zero, the tilt phase is zero, meaning that the beam is pointing straight ahead. 

If you want to steer along the x or the y axis (right or left) the theta steer angle can be changed to achieve this. 

This method can then be applied to different scenarios to achieve different directional steering.

Lastly, an adjustment is applied to ensure that the physics remains accurate.
\begin{equation}
    \exp(1i * tilt_phase)
\end{equation}

This is where the lengths and widths of the codes are used to calculate a center for the mirror, along with ensuring that the dx or physical grid spacing is still accurate in both the x and y directions since one side will be longer than the other.

This function also focuses on applying the tilted coordinates forward along the y axis.

\section*{\centering{\textbf{Fresnel Diffraction}}}
This function uses fresnel teqniques as found in (ref Optical physics third edition) to calculated the diffraction pattern from the aperture onto the mirror. 
Rather than using an FFT here, a double for loop is utilized with the diffraction by Huygen's principle:
\begin{equation*}
    E(x',y') = \iint A(x,y) \frac{e^{ikd}}{d} dx dy 
\end{equation*}
This ensures that the actual math for the Fresnel diffraction is preserved and accurate in the near field, rather than approximating it with FFT teqniques. 

This function also accounts for the complex phase shift that is created from the tilted mirror

\subsection*{\centering{\textbf{Phase Adjustment for Non-flat Mirror}}}

This function applies a phase mesh to change the complex fields of the Near field output. The following phase array helps to convert uneven surface height on the mirror map into a phase delay map.

\begin{equation}
    \phi(x,y) = \frac{2 \pi}{\lambda} 2 h(x,y)
\end{equation}

This equation is broken down in the function to calculate the phase mask (derived from Eulers formula) and tranform the real numbers into complex 2d phasors. That are then matrix multiplied to give an output of the uneven mirror.
